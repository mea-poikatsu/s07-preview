ゲーム概要

中世を舞台にした戦略シミュレーション×放置サバイバル。領主として生存者に仕事を割り当てて都市を再建し、施設建設・技術研究・英雄編成・同盟運営で国を育てていきます。

到達目安・達成データ

「課金なら何日・無課金なら何日」という目安は、このゲームでは裏付け付きでは作れません。最も大きな実測材料（ワラウ利用者集計・約800件）が課金の有無を区別していないためです。代わりに、確認できている実測データをそのまま載せます。

トゥルーゴールドLv1・Lv3到達報告なし2026-11-26の収集範囲で確認できず

役場Lv24の28日は1件の報告のため、平均（目安）としては扱いません。Lv28以降は、役場の基礎時間の累積から「加速と同盟支援の総動員が前提」と推定される段階で、到達可否は未確認です。

プレイ形の目安として、ワラウ集計では「1日合計1〜2時間＋建築完了・採集帰還に合わせた5分程度のこまめなログイン」が最適形とされています。10日期限のステップがあるため、初日に数時間プレイできる日に開始するのが安全です。

効率的な進め方（要約）

進め方の骨格は「チャプター最優先→役場を優先強化→同盟に即加入→前提建物を先行→日課を固定」の5点です。詳細は各トピックページにまとめています。

チャプター資源・加速の入手源
→
役場を優先新施設の前提
→
同盟加入役場6で解放
→
前提を先行第2建築枠
→
日課を固定回収→建造→訓練

役場Lv16以降は前提建物（大使館＋兵営／射撃場／騎兵営／学院のローテーション）の基礎時間自体が1日を超えます。第2建築枠で前提を先行建築しておかないと役場が止まるため、建築枠の確保が序盤の最重要ポイントです。
