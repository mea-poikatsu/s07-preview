キングショットのポイ活攻略

中世を舞台にした戦略シミュレーション×放置サバイバル。ポイ活ではレベル到達などを条件とするステップアップ案件が各ポイントサイトに掲載される。ワラウではStepUp案件（最大21,600pt・全11ステップ）、ハピタスでは金額の異なる2つのステップアップ掲載（25,008pt／20,500pt）が併存し、25,008pt掲載はOS別（iOS／Android）に分かれていることを公式ページで確認した（2026-11-26再実読で訂正）。

ポイ活で始める場合、このゲームの案件はワラウ・ハピタス・Freecashに掲載されています。掲載先によって最大ポイントや達成条件が異なるため、始める前にキングショットの案件条件・ステップ一覧で比較するのがおすすめです。案件ページを経由してインストールし、期限内に条件を達成するとポイントが付きます。

攻略の要点

  • 役場レベルの上げ方と到達目安：条件の中心は本拠地「役場」のレベル到達。序盤はチャプターミッションに沿って進めるのがガイドになり、役場9で学院が解放されたら（海外の建物データベース複数で役場9に一致。国内ガイドには役場8とする記述もあり、そちらは未確認として注記）研究を同時並行で始めるのが基本になる。役場Lv20の到達は実践により4日目〜10日目と幅がある。案件によっては期限が10日程度と短い設定があるため、プレイ時間を確保できる日に開始するのが安全。
  • 役場（タウンセンター）要件表と前提ローテーション：役場の前提はLv16以降「大使館（常に役場Lv−1）＋兵営／射撃場／騎兵営／学院のローテーション」で回る。基礎時間は Lv20 で3日10時間、Lv30 で40日4時間に達し、前提側の累積だけで35日期限を超えるため、国内型の最終ステップは加速と同盟支援の総動員が前提の設計
  • トゥルーゴールドの解放条件と到達ライン：トゥルーゴールド進行は役場Lv30到達だけでは始まらず、自分のプレイ日数ではなくサーバー（王国）年齢70日の経過が別途必要。Freecash型の最終ライン TG3 は、役場30＋王国70日＋TG段階の基礎時間の累積を加速で圧縮する前提の到達ライン
  • 到達目安の材料（ワラウ利用者集計）：ワラウ利用者約800件の集計（課金混合）では、役場Lv8＝達成率92%・平均11時間、Lv16＝67%・平均4日、Lv20＝29%・平均7日。課金／無課金に分けた平均はこの集計からは作れないため、正式な目安（課金：目安○日／無課金：目安○日）は作らず、集計の実測値をそのまま提示する
  • 到達報告の収集型の実施結果（2026-11-26）：収集型（課金有無・課金額・日数が読み取れる報告だけを母数）で集めた結果、役場Lv24は課金800円の実践報告で28日が1件のみ、Lv28到達・Lv30完走・トゥルーゴールド完走は0件だった。母数が足りず、Lv24超のゾーンの到達目安は作れない
  • 序盤の進め方（3ステップと日課）：序盤は①チャプターミッション最優先②役場を優先強化③日課を固定、の3ステップ。リセマラは不要（強力なジェベルがログイン2日目に無料入手できる）。同盟は役場6の解放直後に加入する
  • 英雄の世代・Tierと育成方針：英雄は世代（Gen）ごとに伝説3人（Gen1のみ4人）が追加され、ポイ活期間（〜100日）に関係するのは Gen1〜Gen2 が中心。育成は主力5人に集中し、無課金は各世代の英雄ルーレット英雄を柱にする。欠片は戻らない資源なので選び間違いが長期コストになる
  • 同盟・巨熊狩猟と資源確保：同盟Lv5以上で開催される巨熊狩猟（ベアトラップ）の報酬が資源確保で最大級。活発な上位同盟への早期加入が到達の成否を分ける。同盟は役場6で解放され、解放直後の加入が基本
  • ギフトコード（2026-11-26確認）：2026-11-26時点で有効なのは THANKS4WORK／KS27TGS／FORTHEKINGDOM／VIP777 の4件を主とし、SAYHIHI は期限切れの可能性が高い。コードは開始直後に入力するのが定石で、掲載は当日確認したものだけに限る（失効コードの転載事故を防ぐため）
  • 課金ステップの順序と現実的課金プラン：国内StepUp型の課金ステップは段階制で、後段は「先に役場レベル到達」が条件のため順序を間違えると成果にならない。時短効果が複数出典で裏付けられた現実的課金は第2建築枠の確保（150円級パック）のみで、それ以外の課金はポイ活期間での回収裏付けがない
  • イベント周期の骨格と進捗連動：イベントは週次（同盟選手権・英雄ホール）／隔週（城戦・剣の地対決・英雄ルーレット）／28日周期（王国の力・三同盟衝突）の骨格で回り、初回KvK後は4週スーパーサイクルになる。ポイ活の進捗と直結するのは、育成・建設がスコアになる最強領主系と、世代英雄の入手路である英雄ルーレット
  • 英雄のスキル体系と欠片（シャード）コスト：英雄の欠片は全英雄共通の星上げ体系（星1〜5で合計1,065個）で、解放コストは通常10個・アマデウス20個・チェンコ40個。アマデウスとヘルガは専用欠片のみで強化できる。スキルは征服3＋遠征3（伝説。専用装備で各＋1）／遠征はEpicで2つに減り、集結参加時は左端スロット英雄の遠征スキル1のみが効く
  • 学院の研究ツリー（191プロジェクトの構造と優先順位）：学院の研究は成長45／経済44／戦闘102の計191プロジェクト。全量完了は基礎時間で数千日規模のため、ポイ活期間に効くのは成長ツリー序盤（研究速度・建設速度・行軍枠）と部隊展開容量のみ。優先は Tool Enhancement（研究速度）→Tooling Up（建設速度）→Command Tactics（行軍枠＋1、学院Lv2帯）→Regimental Expansion（展開容量）の順

注意点

StepUpには課金系ステップ（初回課金・累計課金回数）が混ざる構成があり、最小課金は150円クラスのパック（新人応援パック等）で済むという報告が複数ある。累計課金ステップは「初回課金が1回目にカウントされる」ため、回数稼ぎの重複購入は不要という注意がある。ダイヤの使い道は建築時間の短縮と第二建造隊列の雇用を主とし、それ以外では温存する。資源不足でレベルアップが止まるのが典型的な失速パターン

基礎値はボーナスを含まない素の値。実際の所要時間は研究・同盟支援・加速で圧縮される

TGの現行上限は TG8 とする出典と TG1〜TG10 の表を載せる出典が対立（未確定）。案件の到達ラインは TG3 までで実務影響は小さい

課金の有無は考慮されていない集計。対象は掲載時期の案件形態で、現行案件の期限・ステップとは異なる場合がある

n=1 の値は平均（目安）にせず、件数を明示した個別値として扱う。案件側の到達目安表示（アメフリ等）は実測ではないため裏付けに使わない

放置報酬9時間の数値は単独出典の参考値

Tierは各攻略サイトの評価で、公式の順位付けは存在しない。出典により評価が割れる英雄がある（マリン等）

巨熊の開催条件・周期はサーバー状況で変わる場合がある

季節コード（感謝祭・ブラックフライデー名義）の新規コードは2026-11-26時点で存在しないことを5サイト横断で確認

第2建築枠の国内価格（150円級）と海外の恒久パック価格（US$2.99）が同一商品かは未確認

開催周期はサーバー年齢・世代で変わる観測パターン。実施の確認はゲーム内イベントタブが正

未確定3点（Sophia の Lash 追加ダメージ 12%／24%、Charles の Vengeance 自己攻撃バフ +100%／+140%、Diego の Blade Soul Lv2 2%／3%）は出典間で食い違うため確定値として扱わない。一部スキル（Liz の Bubbletopia 等）は中間レベルの数列が未取得（最大値は取得済み）
