試験管ソルバー

37GAMES｜iOS/Android｜ミニゲーム「エヴァの試験管実験」用ツール

更新日：2026年11月25日

ミニゲーム「エヴァの試験管実験」（ウォーターソートパズル）の解答ツールです。スクリーンショットから色を読み取るか、タップで色を入力すると、最短手順を計算して1手ずつシミュレーションで確認できます。計算はすべてこのページの中で完結し、画像や入力内容が外部に送信されることはありません。

このツールの要点
スクショ読み取り＋手動修正の両対応です。色が読み取れなかったマスは「？」になり、色の仮定を自動で試して解を探します。「？」が多いときは「？開放優先」モードで、まず「？」を露出させる手順だけを出すこともできます。
スクショ対応最短手順（BFS）「？」仮定探索あり「？」開放優先モード外部送信なし

使い方

3ステップ＋解く
1
スクショを読み込む

「スクショから読み取る」タブで、試験管実験の画面のスクリーンショットを選ぶか貼り付けます。画像なしで解きたい場合は「タップで手入力」タブでも使えます。

2
グリッドを合わせて色取得

段数・1段の本数・グリッドの位置と間隔をスライダーで合わせ、「色を取得する」を押します。ずれたマスは、下のパレットで色を選んでマスをタップすれば手動で直せます。

3
解く → 手順どおりに進める

「最短手順を解く」を押すと手順の一覧とシミュレーションが出ます。「次へ／前へ」で1手ずつ確認しながら、ゲーム内でそのとおりに注いでください。

コツ：「？」が多い場合 ― 色が判定できない「？」マスが多いときは、そのままでは解けないことがあります。ソルバーのモードを「？開放優先」に切り替えて解くと、「？」を覆っている上の色をどかして「？」を露出させる手順が出ます。その手順を進めてから画面を撮り直し、もう一度読み取ると正確に解けます。

試験管ソルバー

入力 → 解く → 手順確認

1. スクリーンショット

ファイルを選ぶか、このページに画像を貼り付け（ペースト）してください

画像はこのページの中だけで処理します。外部サーバーへは送信しません。

2. グリッド合わせ

グリッドの枠が各試験管の色水のマスに重なるよう調整してください。各マスの中心周辺の平均色を読み取り、パレットに最も近い色へ割り当てます。距離が遠い・暗すぎるマスは「？」になります。

タップ手入力の準備

下のパレットで色を選んでからマスをタップすると、その色で塗れます。分からないマスは「？」、空のマスは「空」を選んでタップしてください。

3. 色の確認・修正（パレット → マスをタップ）

マスは下が試験管の底、上が口です。色は下から詰めて入力してください（途中の空マスは詰め直して扱います）。

4. 解く

0 / 0 手

薄い赤背景の手順は、その手で「？」がめくれて見えるようになる手です。ゲーム内でもそのタイミングで色を確認してください。

解けないときの確認

よくある原因

  • 色の数え違い：同じ色は原則として容量（基本4マス）分だけ存在します。1色が5マス以上ある・3マスしかない場合は、どこかのマスの色が間違っている可能性が高いです
  • 「？」の残り：「？」がある配置は仮定探索で解を探しますが、試行上限（初期値50回）を超えると解けない場合があります。上限を上げるか、「？開放優先」で露出させてから撮り直してください
  • 探索上限：本数が多い配置は計算量が大きく、探索上限に達すると「解が見つかりませんでした（上限到達）」と表示します。入力ミスがないか確認してから再試行してください
